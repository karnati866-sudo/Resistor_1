1. Register Definition | రిజిస్టర్ నిర్వచనం

English: A register is a small, high-speed storage location inside a CPU or digital circuit. It temporarily stores binary data, instructions, addresses, or intermediate results.

తెలుగు: రిజిస్టర్ అనేది CPU లేదా డిజిటల్ సర్క్యూట్‌లో ఉండే చిన్న మరియు చాలా వేగంగా పనిచేసే తాత్కాలిక నిల్వ స్థానం. ఇది binary data, instructions, addresses లేదా intermediate results‌ను కొంతకాలం నిల్వ చేస్తుంది.

Fast | వేగవంతమైనది
Registers are very fast storage elements.
రిజిస్టర్లు చాలా వేగంగా పనిచేసే storage elements.
Binary | బైనరీ
They store information as 0s and 1s.
ఇవి సమాచారాన్ని 0 మరియు 1 రూపంలో నిల్వ చేస్తాయి.
Temporary | తాత్కాలికం
Data is held while it is needed.
అవసరమైన సమయంలో డేటాను తాత్కాలికంగా ఉంచుతుంది.

3. Types of Registers | రిజిస్టర్ల రకాలు

Register | రిజిస్టర్Purpose | ఉపయోగం
Accumulator (ACC)
అక్యుమ్యులేటర్		Stores intermediate arithmetic and logic results.
Arithmetic మరియు Logic operations ద్వారా వచ్చిన intermediate results‌ను నిల్వ చేస్తుంది.
Program Counter (PC)
ప్రోగ్రామ్ కౌంటర్		Stores the address of the next instruction.
తదుపరి instruction యొక్క address‌ను నిల్వ చేస్తుంది.
Instruction Register (IR)
ఇన్‌స్ట్రక్షన్ రిజిస్టర్		Holds the current instruction.
ప్రస్తుతం process అవుతున్న instruction‌ను ఉంచుతుంది.
Memory Address Register (MAR)
మెమరీ అడ్రస్ రిజిస్టర్		Holds the memory address being accessed.
Access చేయాల్సిన memory address‌ను ఉంచుతుంది.
Memory Data Register (MDR)
మెమరీ డేటా రిజిస్టర్		Temporarily holds data moving to or from memory.
Memoryకి వెళ్లే లేదా Memory నుంచి వచ్చే data‌ను తాత్కాలికంగా ఉంచుతుంది.
General-Purpose Register
జనరల్ పర్పస్ రిజిస్టర్		Stores data used during program execution.
Program execution సమయంలో అవసరమైన data‌ను నిల్వ చేస్తుంది.

5. 8-Bit Register Simulation | 8-బిట్ రిజిస్టర్ సిమ్యులేషన్

English: Enter an 8-bit binary value, load it, and press the clock button to store it in the register.

తెలుగు: 8-bit binary value‌ను నమోదు చేసి, Load Input నొక్కండి. తరువాత Clock నొక్కితే ఆ value register‌లో store అవుతుంది.


Register Output | రిజిస్టర్ అవుట్‌పుట్: 0 decimal

Register is cleared. Press Load Input and then Clock ↑.
రిజిస్టర్ క్లియర్ అయింది. Load Input తరువాత Clock ↑ నొక్కండి.

How to use | ఎలా ఉపయోగించాలి

  1. Enter 8 binary digits — 0 or 1.
    8 binary digits — 0 లేదా 1 — నమోదు చేయండి.
  2. Click Load Input.
    Load Input నొక్కండి.
  3. Click Clock ↑ to store the value.
    Value‌ను register‌లో store చేయడానికి Clock ↑ నొక్కండి.
  4. Observe the eight register bits.
    రిజిస్టర్‌లోని 8 bits‌ను గమనించండి.
